# Security Policy

## Supported Versions

Security fixes are provided for the latest version on the default branch.
Older versions may not receive security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities in a public issue.

Report vulnerabilities privately through the repository's GitHub security
advisory feature or by contacting the maintainer through the contact details
on the project GitHub profile. Include:

- A clear description of the vulnerability.
- The affected component and version or commit.
- Steps to reproduce the issue or a proof of concept.
- The potential impact and any suggested mitigation.

You should receive an acknowledgement within 7 days. We will investigate the
report, keep you informed of progress where possible, and coordinate a fix and
public disclosure timeline with you.

Please avoid accessing, modifying, or deleting data that does not belong to
you while investigating a suspected vulnerability.
